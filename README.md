# MeerLezen

Een leesapp voor de schoolbibliotheek. Kinderen kiezen op zin, zoeken op onderwerp, scannen een boek, krijgen tips van leesmaatjes Toet en Bas, en geven een boek een gezichtje.

Dit is een **prototype**: de titels zijn echte kinderboeken, maar de kaften, tellingen en beoordelingen zijn voorbeelden.

## Afspraken over gegevens

Deze repository is **openbaar**. Iedereen kan alles lezen wat hier staat. Daarom:

- Hier staan alleen boeken en testleerlingen (zoals "Leerling 001, groep 5"), nooit echte namen.
- Zoekopdrachten en foto's worden niet bewaard.
- Geheime sleutels komen nooit in deze repository.
- Pas als we echte uitleningen of leespassen gaan bijhouden, verhuizen die gegevens naar een aparte database, en pas nadat de school akkoord is.
