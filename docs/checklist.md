# Checklist: voorbereiding bibliotheekproject

Regel deze punten vóór onze eerste sessie; reken op zo'n uur werk, verspreid over een week. We bouwen samen met AI een app om je schoolbibliotheek te beheren en delen de code via GitHub. Jij zit aan het stuur, ik denk mee via het scherm. We beginnen met een boekencatalogus, zonder gegevens van leerlingen.

## 1. Accounts en toegang

- [ ] Maak een gratis account aan op [github.com](https://github.com) en stuur mij je gebruikersnaam.
- [ ] Ik nodig je uit voor onze repository. Je krijgt een mail: klik op **View invitation** en daarna op **Accept invitation**.
- [ ] Maak een account aan op [claude.ai](https://claude.ai). Voor Claude Code, waarmee we samen in de code werken, is een betaald abonnement (Pro) nodig. Deze kan je voor 1 maand nemen, is ongeveer 25 euro. Ziet het als een avondje uit eten, das even duut.

## 2. Techniek

- [ ] Werk op een laptop of desktop, niet op een tablet, met een actuele browser (Chrome of Edge).
- [ ] Zorg voor oortjes of een headset, dan hoor je geen echo.
- [ ] Handig: een groot scherm of een tweede scherm, zodat Claude en de app naast elkaar passen.
- [ ] Hou je telefoon bij de hand. Later willen we misschien barcodes van boeken scannen.

## 3. De bibliotheek in kaart

Dit is het belangrijkste huiswerk: wat jij hier opschrijft, vertel je in de sessie zelf aan Claude. Een paar steekwoorden per vraag is genoeg; je kunt ze gewoon in een notitie op je telefoon zetten.

- [ ] Hoeveel boeken zijn er ongeveer? Tientallen, honderden, duizenden?
- [ ] Hoe wordt het nu bijgehouden: een schrift, een Excel-bestand, of helemaal niet?
- [ ] Wie lenen er? Welke klassen of groepen, en om hoeveel leerlingen gaat het ongeveer?
- [ ] Wie doet het uitlenen: jij, een collega, leerlingen, vrijwilligers?
- [ ] Hebben de boeken een barcode, ISBN-nummer of eigen sticker?
- [ ] Heb je al een idee wat je wil bereiken met je app?
- [ ] Wat wil je aan het eind van het schooljaar kunnen zien of weten?
- [ ] Gebruikt de school al een systeem, bijvoorbeeld via de openbare bibliotheek (Bibliotheek op school)?
- [ ] Maak een paar foto's van hoe het nu gaat: de kast en een etiket op een boek. Geen foto's van pagina's met namen van leerlingen.

## 4. Afspraken over gegevens

We bouwen eerst een versie zonder gegevens van personen. Een boekencatalogus bevat geen persoonsgegevens, dus daarmee kunnen we meteen beginnen.

- [ ] Plak ook in Claude nooit echte gegevens van leerlingen.
- [ ] Als je echt iets gaat bouwen wat je wil gebruiken ben je toestemming nodig.

## 5. Eerste sessie plannen

Doel van sessie 1: een eerste versie van de **catalogus** met 10 echte boeken, en jouw eerste wijziging in de repository via een pull request.

- [ ] Plan met mij een moment van 60 tot 90 minuten.
- [ ] Zorg dat je bij de start ingelogd bent op claude.ai en op github.com.
- [ ] Leg je antwoorden van stap 3 en de foto's klaar.
- [ ] Pak 10 boeken uit de bibliotheek om mee te oefenen.
